Project status

Project status describes whether work on a project is currently taking place.

StatusMeaning
● ActiveThe project is currently being worked on.
⏸ On holdWork is temporarily paused, but the project is expected to continue.
○ InactiveThe project is currently not being worked on and there is no immediate plan to continue.
■ ClosedThe project is no longer active.

Project phases

Project phase describes the current stage in the development lifecycle.

PhaseDescription
🔍OrientationCollecting information, requirements, references and inspiration.
💡Concept DevelopmentExploring possible solutions and comparing different concepts.
📐DesignDeveloping the selected concept into a more detailed design.
🛠️PrototypeBuilding and testing one or more prototypes.
🚀RealisationBuilding or implementing the final solution.
✅CompletedThe intended result has been completed.
📦ArchivedThe project is retained for reference, but no further development is planned.
